Remembering a filament layout

An applied assignment currently lives on one Print object. Re-slice or reopen the project and it is gone — the plate quietly goes back to whatever the optimiser prefers. Persistence stores the layout with its plate, in the 3MF.

That is straightforward plumbing. What it changes on screen is not, and that is what these three states are for. Numbers below are the real ones from the 7-colour cube on Snapmaker U1 (0.4 nozzle) - multiACE: auto costs 300 swaps / ~40.4 g, the hand layout costs 349 / ~47.0 g.

State AFresh plate — nothing remembered
Situation
The plate has never been assigned by hand.
Behaviour
Unchanged from today: opens in Auto on the computed plan.

Nothing to decide here — included as the baseline the other two are read against.

State BReopened project — layout remembered
Situation
The project was saved after applying a hand layout, then reopened and re-sliced.
Must claim
The layout in force is the user's 349, and a free optimum would still be 300.
At stake
Whether the plate says it is carrying a saved layout, and what it cost.

State CRemembered layout no longer fits
Situation
The layout was saved for 7 filaments; the project now has 5.
Behaviour
The layout is dropped — it no longer refers to the same spools — and the plate is planned fresh.
At stake
Whether dropping it is said out loud or done silently.

The slicer already drops it on a size mismatch; that part is written. The only question is the banner: say it, or stay quiet? Saying it costs a line of chrome on a plate the user may have stopped caring about. Staying quiet means a layout they deliberately saved disappears with no trace.

Settled — this is what was built

  1. State B: proposed. C++ sends a remembered layout as manual rather than as pins, so the page's optimiser runs unconstrained and Auto would need 300 is a real comparison.
  2. Handing the plate back is Use auto instead in the banner. It switches to Auto; applying in Auto then clears the stored layout.
  3. State C says it, with Dismiss for this opening only — dismissing hides the banner, it does not delete the layout, so the plate keeps it in case the filament count comes back.
  4. Hand layouts only. Applying in Auto clears any stored layout rather than freezing today's answer onto a plate whose colours may change.

One deviation from the drawings above, since corrected here: the instruction hint stays below the banner instead of being replaced by it. Someone reopening a project to adjust a layout needs "drag spools between positions" more than they need the extra whitespace.
