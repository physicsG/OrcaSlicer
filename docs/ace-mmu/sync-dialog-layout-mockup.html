Sync Filament — layout redesign

Today the dialog has two fixed left labels — Source Filament / Printer Filament — beside a wrapping grid of mapping cards. With more than 4 filaments the cards wrap to a second row that the labels no longer line up with, so it reads as broken. Two redesigns below make each card self-describing (top = project filament → bottom = printer filament) and scale to any number of filaments. Data = your live 6.

Both drop the fixed left labels and describe the mapping per row instead, so any number of filaments lays out cleanly. Option A keeps today's card look (least code change — reuse the existing FilamentColorMapBox, just remove the label column and let the grid flow). Option B is a denser table that reads top-to-bottom and stays compact even with 10+ filaments (more work — a new row widget). My recommendation: Option A first (small, safe), Option B later if you want the density.
