What is in this build

  • Initial auto-load block before the prime line
    One ACE_SWAP_HEAD per ACE-fed head at its first slot, in multiACE's own format and position, so head 3 no longer assumes it already holds the right colour.
  • multiACE topology moved to Printer settings → Multimaterial
    Grouped per toolhead. The unit field no longer appears on heads with no ACE, which is what made the wrong field the obvious one to click.

    "multiACE slots on this head (1 = stock feeder)" spells out that 1 means no ACE.

    T<n> and M104/M109 T<n> emit the physical head while per-filament settings still use the logical index.
