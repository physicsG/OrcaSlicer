Showing the ACE→toolhead link. Each U1 toolhead carries a source chip for how it's fed — ACE A · A4 (dot = the feeding slot's colour), Feeder, or Manual — and the feeding ACE slot shows the reciprocal → T4. So the connection reads both ways.

Mode is an ACE setting (configured on the printer — Normal / Multi / Head), shown here read-only because it changes how the panel should read: Head — each head is bound independently (ACE unit / feeder / manual; from head_feeder, head_ace, ace_heads), so the source chip is per-head. Multi — one active ACE feeds via toolchanges; its slots become the logical tools (T = ace*4 + slot), so the ACE group leads and heads collapse to the active one. Normal — a single direct spool, ACE not multiplexing. Multiple ACE units each get their own group. Open question: in Head mode project filaments map to heads; in Multi mode to ACE slots — the exported tool indices differ, to settle while iterating.
